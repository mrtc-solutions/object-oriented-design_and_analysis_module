All generated exam files are in `output/exams/`; only editable sources live here. Use PDFs for printing and DOCX files for Word editing. The Markdown files are the build sources. From the repository root, after installing `requirements.txt` in `.venv`, run `.venv/bin/python tools/build_exam_docs.py` to regenerate all six documents.

Both papers use the same proposed format: **3 hours, 100 raw marks**, Question 1 compulsory (40 marks), plus any three of Questions 2–5 (20 marks each). The course outline assigns 60% of the overall module assessment to the examination and 40% to assessment.

The course outline does not specify the exam duration or format. The lecturer/faculty should approve those details, the timetable and local examination instructions before issuing the papers. Keep the marking guide separate from candidate copies.

This repository is public: these are practice papers, not unseen live examination papers. The examiner label is a distribution warning, not access control.
